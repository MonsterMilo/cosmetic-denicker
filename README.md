# Cosmetic Denicker

Beta. Spots nicked players' cosmetics and finds who they are after the game

## Requires

- hypixel-mod-api
- denicker (optional)

## Commands

- `/clear [confirm]`: Remove all saved nicks
- `/key <key>`: Set your Aurora API key
- `/list`: Nicks in your last game
- `/remove <nick>`: Remove a saved nick
- `/saved`: Show saved nicks
- `/search <nick>`: Find who a nick is
- `/stop`: Stop searching
